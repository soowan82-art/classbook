# 학급일지 (웹앱)

출결, 다이어리, 제출 체크, 학생 기록, 성적, 예산, 자리 배치, 랜덤 뽑기, 일인일역을 한 화면에서 관리하는 학급 운영 웹앱입니다.

- 기록은 각 선생님의 브라우저에 저장되고, 원하면 각자 자기 구글 드라이브의 '학급일지 자동백업 (웹앱)' 폴더에 자동 백업됩니다.
- 구글 드라이브 연동을 쓰려면 `config.js`에 구글 OAuth 클라이언트 ID를 넣어야 합니다. 비워 두면 브라우저 저장만 하는 앱으로 동작합니다.
- 파일: index.html(앱), config.js(설정), manifest.webmanifest·sw.js·icon-*.png(바탕화면 설치용), vercel.json(배포 설정)
