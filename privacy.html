학급일지 개인정보처리방침

시행일: 2026년 11월 13일

학급일지는 선생님이 학급 운영 기록(출결, 학생 기록, 시간표, 업무 등)을 적는 웹앱입니다. 학급일지는 별도의 서버에 정보를 모으지 않습니다.

1. 저장되는 정보와 저장 위치

  • 선생님이 입력한 기록은 선생님이 쓰는 브라우저 안에만 저장됩니다.
  • 선생님이 '구글 드라이브 자동 백업'을 켜면, 같은 기록이 선생님 본인의 구글 드라이브 안 '학급일지 자동백업 (웹앱)' 폴더에 파일로 저장됩니다.
  • 학급일지 제작자를 포함해 다른 누구도 이 기록을 볼 수 없습니다.

2. 구글 계정 정보의 사용

  • 학급일지는 구글 로그인 때 drive.file 권한만 요청합니다. 이 권한으로는 학급일지가 직접 만든 파일만 만들고 읽을 수 있고, 드라이브의 다른 파일은 볼 수 없습니다.
  • 구글에서 받은 정보는 백업 파일을 저장하고 불러오는 데에만 쓰며, 다른 곳으로 보내거나 광고에 쓰거나 사람이 읽지 않습니다.
  • 학급일지가 구글 API로 받은 정보를 쓰는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

3. 보관과 삭제

  • 브라우저의 기록은 브라우저 저장 데이터를 지우면 삭제됩니다.
  • 드라이브의 백업은 선생님이 드라이브에서 '학급일지 자동백업 (웹앱)' 폴더를 지우면 삭제됩니다.
  • 학급일지의 드라이브 접근 권한은 구글 계정 → 서드 파티 앱 및 서비스에서 언제든 해제할 수 있습니다.

4. 제3자 제공

학급일지는 어떤 정보도 제3자에게 제공하지 않습니다.

5. 선생님께 드리는 당부

학급일지에는 학생 개인정보가 들어갈 수 있습니다. 소속 학교의 개인정보 처리 지침에 맞게 사용해 주시고, 여러 사람이 쓰는 공용 컴퓨터에서는 사용하지 마세요.
